# DESIGN.md

## Zasady UI

- Nie dodajemy słów-wypełniaczy bez powodu. Interfejs ma tłumaczyć się sam: jeśli element jest oczywisty z kontekstu (np. pole wyszukiwania, rząd przycisków z liczbami), nie opisujemy go widocznym tekstem.
- Dostępność zostaje: elementy bez widocznej etykiety dostają `aria-label`.
